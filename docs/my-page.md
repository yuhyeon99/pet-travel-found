# My Page (/my)

- 위치: `src/pages/MyPage/index.jsx`.
- 접근 제어: 마운트 시 `isAuthenticated()` 확인, 비로그인 시 알림 후 `/auth/login` 이동. 인증 확인 전에는 `null` 반환으로 깜빡임 방지.
- 구성 요소
  - `UserInfo`: 세션의 사용자 이름/이메일 표시, 로컬스토리지 `payment` 중 본인 예약 건수 카운트, 로그아웃 버튼(`logout()` 후 `/` 이동).
  - `BookingLists`: 로컬스토리지 `payment`에서 사용자 이메일로 필터링한 예약 건을 카드 형태로 렌더. 없으면 “예약 내역이 없습니다.” 메시지.
  - `BookingList` 항목: 체크인/체크아웃, 숙박 박수, 인원, 예약일, 가격을 표시. 상태 태그는 현재 `결제완료` 고정.
- 데이터 저장소: 결제 기록은 `setPayment`가 추가한 로컬스토리지 `payment` 배열을 사용.
- 주의사항: 서버 동기화 없음; 다른 브라우저/기기 간 데이터 공유 불가.
